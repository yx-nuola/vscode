WebviewA： 显示在activitybar区域， 显示上传， 解析按钮， 文件列表
WebviewB： 展示在editor区域， 左右布局， 左侧为二维图形， 右侧为表格
Extension： vscode插件的扩展层，用于解析数据，传递数据给页面 webview















用户操作流程：
┌─────────────────────────────────────────────────────────────┐
│ 1. WebviewA (ActivityBar)                                   │
│    ├── 用户点击"选择文件"                                    │
│    ├── 打开文件选择对话框                                    │
│    └── 发送文件路径到Extension                               │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│ 2. Extension (Node.js)                                      │
│    ├── 读取文件内容                                          │
│    ├── JSON解析                                             │
│    ├── 数据校验 (格式、字段)                                 │
│    ├── 构建位置索引 Map<"x-y", index>                      │
│    ├── 存储到内存 allData[]                                  │
│    └── 发送"数据准备就绪"到WebviewB（带有页面数据）            │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│ 3. WebviewB (Editor)                                        │
│    ├── 初始化Konva画布 (左侧)                                │
│    ├── 初始化VTable表格 (右侧)                               │
│    ├── 预加载前100条数据                                     │
│    └── 显示数据统计信息                                       │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│ 4. 用户滚动/点击交互                                         │
│    场景A: 滚动表格                                           │
│    ├── VTable触发scroll事件                                  │
│    ├── 计算可见区域 (startRow, endRow)                       │
│    ├── 检查缓存，有数据直接显示，发现缺失数据                   │
│    ├── 发送"requestData"到Extension                          │
│    ├── Extension返回数据块                                    │
│    └── 更新表格和格子视图                                     │
│                                                              │
│    场景B:  点击表格行                                         │
│    ├── VTable触发click_cell事件                              │
│    ├── 获取rowIndex                                          │
│    ├── 如果数据未加载，发送"requestData"                     │
│    ├── 获取cellData (x, y)                                │
│    ├── 滚动格子视图到对应位置                                │
│    └── 选中格子和表格行                                      │
│                                                              │
│    场景C:点击格子                                             │
│    ├── Konva触发click事件                                    │
│    ├── 获取bl, wl坐标                                        │
│    ├── 发送"findCellByPosition"到Extension                   │
│    ├── Extension查找索引，返回index                          │
│    ├── 如果数据未加载，发送"requestData"                     │
│    ├── 滚动表格到对应行                                      │
│    └── 选中表格行和格子                                      |
│    场景D:滚动格子                                             │
│    ├── Konva触发scroll事件                                    │
│    ├── 获取bl, wl坐标                                        │
│    ├── 发送"findCellByPosition"到Extension                   │
│    ├── Extension查找索引，返回index                          │
│    ├── 如果数据未加载，发送"requestData"                     │
│    ├── 滚动表格到对应行                                      │
│    └── 选中表格行和格子                                      │
└─────────────────────────────────────────────────────────────┘
